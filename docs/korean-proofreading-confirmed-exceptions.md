# 한글 번역 검수 — 사용자 확정 예외 행

이 문서는 전체 번역 검수에서 **사용자가 해당 행을 직접 문제없다고 지정한 항목만** 기록한 예외 목록이다.

- 이 목록은 번역 전체가 정상이라는 뜻이 아니다.
- 같은 표현이 다른 행에 나타나도 자동으로 제외하지 않는다.
- 아래 위치의 정확한 행만 재검수 시 예외로 취급한다.
- CSV의 현재 키를 기준으로 기록했으며, `stringsImportK.csv`의 행 자체는 수정하지 않았다.
